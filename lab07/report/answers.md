# Ответы на контрольные вопросы

1. Низкий Train Loss не гарантирует обобщение: сеть могла запомнить обучающие объекты.
2. Control нельзя использовать для настройки, иначе финальная оценка перестаёт быть независимой.
3. MSE не отражает дискретную ошибку класса; для классификации нужны вероятности и confusion matrix/F1.
4. Временной ряд нельзя перемешивать: порядок является частью задачи, а будущие значения недоступны в прошлом.
5. One-step прогноз оценивает следующий шаг при известных фактических лагах; рекурсивный мног шаговый прогноз накапливает собственные ошибки.
6. Сложная сеть может переобучиться, поэтому сравнивают Test и число параметров.
