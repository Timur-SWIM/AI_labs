# Теория ЛР7

Аппроксимация моделирует непрерывную зависимость и оценивается MSE/RMSE/MAE/R². Классификация использует softmax и cross-entropy, а качество описывается accuracy, macro-F1 и матрицей ошибок. Временной ряд строится из прошлых лагов с хронологическим Train/Test/Control; перемешивание и использование будущих значений запрещены.

Преобразования признаков обучаются только на Train. Test используется для выбора модели, Control — один раз после фиксации решения.
