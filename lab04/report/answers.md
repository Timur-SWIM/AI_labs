# Ответы на контрольные вопросы

1. Нейрон формирует `Σw_i x_i+b` и применяет активацию; bias сдвигает порог.
2. Нелинейная активация нужна, чтобы несколько слоёв могли моделировать
   нелинейные зависимости; без неё сеть сводится к одной линейной функции.
3. XOR неразделима одной прямой, поэтому скрытый слой необходим.
4. Backpropagation вычисляет градиенты ошибки, Adam/SGD/L-BFGS используют их
   для обновления весов; L-BFGS также применён как сравнение для XOR.
5. Classification выдаёт класс, regression — непрерывное значение; поэтому
   для них используют разные выходы и метрики.
6. CV уменьшает зависимость оценки от одного разбиения. Для классификации
   используется stratified CV, сохраняющая пропорции классов.
7. Accuracy может скрывать ошибку редкого класса, поэтому дополнительно нужны
   Precision, Recall, F1 и confusion matrix.
8. MAPE плохо подходит для `y=x²`, потому что в наборе есть `y=0`; применены
   MSE, RMSE, MAE и R².
9. В Orange Predictions получает Data и Model, а Test and Score — Data и
   Learner. Эти подключения приведены в `orange_workflow.md`.
