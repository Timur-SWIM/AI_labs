# Теория

Искусственный нейрон вычисляет линейную комбинацию входов `z=Σw_i x_i+b`,
где `w_i` — веса, а `b` — bias, и пропускает её через функцию активации.
Identity возвращает `z`, Sigmoid сжимает значение в (0,1), `tanh` — в (-1,1),
ReLU равна `max(0,z)`. MLP — это feed-forward сеть из последовательно
соединённых слоёв.

При обучении с учителем сеть получает пары «признаки — правильный ответ».
Loss измеряет ошибку. Backpropagation вычисляет градиенты по правилу цепочки,
а оптимизатор изменяет параметры. SGD делает шаги по мини-батчам, Adam
адаптирует шаги по моментам градиента, L-BFGS использует приближение второго
порядка. Эпоха — проход по всему набору, итерация — один шаг оптимизатора.

Train используют для настройки, test — для независимой проверки, CV делит
данные на несколько обучающих/проверочных частей.
Classification выбирает класс, regression предсказывает число. Accuracy (CA)
— доля верных ответов; Precision — доля верных среди предсказаний класса;
Recall — доля найденных объектов класса; F1 — гармоническое среднее Precision
и Recall. Для регрессии MSE — средний квадрат ошибки, RMSE — его корень, MAE
— средняя абсолютная ошибка, R² — доля объяснённой дисперсии.
