# Теория

Технический нейрон суммирует входные сигналы с синаптическими коэффициентами
и порогом. Для биполярного образа `x_i∈{-1,+1}` Hamming-слой сравнивает вход
с эталоном `w_j`. Нормированный потенциал в этой работе:

`h_j = 0.5 + (x · w_j)/(2n) = 1 - d_H(x,w_j)/n`.

Таким образом, одинаковые образы дают 1, а полностью противоположные — 0.
Сеть feed-forward передаёт сигнал только вперёд: Hamming-потенциалы поступают
на слой сравнения и выбирается наибольший. Recurrent MAXNET использует
взаимное торможение:

`y_i(k+1)=max(0, y_i(k)-ε Σ_{j≠i} y_j(k))`.

При `0<ε<1/(m−1)` для `m` нейронов процесс устойчив, а победителем считается
единственный ненулевой нейрон. Компаратор сравнивает две величины и передаёт
большую; последовательный турнир компараторов реализует feed-forward MAXNET
без вызова `argmax`.
