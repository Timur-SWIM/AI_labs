# Ответы на контрольные вопросы

1. Сеть Хемминга классифицирует вход по минимальному расстоянию Хемминга до
   набора эталонов.
2. Для бинарных образов расстояние Хемминга — число позиций, в которых два
   образа различаются. В работе используется биполярная форма `{-1,+1}`.
3. Потенциал Hamming-нейрона равен нормированной доле совпадений:
   `h=1-d_H/n`.
4. Feed-forward MAXNET выбирает максимум последовательностью двухвходовых
   компараторов; это реализовано в `src/maxnet_feedforward.py`.
5. Recurrent MAXNET подавляет каждый нейрон суммой активаций остальных и
   повторяет шаги до одного победителя.
6. ε задаёт силу взаимного торможения. Слишком большое ε может нарушить
   устойчивость, поэтому используется условие `ε<1/(m−1)`.
7. При равных потенциалах в компараторе побеждает первый встретившийся
   индекс; это обеспечивает детерминированное правило разрешения ничьей.
8. Шум увеличивает расстояние до правильного эталона и может изменить
   победителя. Эксперимент `noise_trials.csv` измеряет это статистически.
9. Возмущение весов изменяет потенциалы даже при неизменном входе; результаты
   находятся в `weight_perturbation.csv`.
10. Число итераций MAXNET зависит от ε: изменение ε меняет скорость
    торможения. Полный sweep сохранён в `epsilon_sweep.csv`.
