# Теория

Многослойный персептрон (MLP) состоит из полносвязных слоёв. Прямой проход
для слоя вычисляет `z^(l)=a^(l−1)W^(l)+b^(l)`, после чего скрытый слой применяет
нелинейность `a^(l)=tanh(z^(l))`. В работе выходной слой линейный и выдаёт две
координаты. Функция потерь — средний квадрат ошибки (MSE).

Backpropagation применяет правило цепочки от выхода к входу. Для MSE сначала
находится производная по выходу, затем для каждого скрытого слоя она
умножается на транспонированные веса и производную `tanh`: `1−tanh²(z)`.
Градиенты весов имеют вид `(a^(l−1))ᵀδ^(l)`, bias — сумма `δ` по примерам.
Adam использует экспоненциальные моменты градиента; SGD делает обычный шаг
против градиента. Learning rate задаёт размер этого шага.

Эпоха — один полный проход обучения по train-набору. Test используется для
сравнения архитектур и оценки генерализации, control — для окончательной
независимой проверки. Генерализация означает низкую ошибку на новых данных.
Overfitting проявляется снижением train loss при ухудшении test loss.

При больших входах `tanh` насыщается около ±1, её производная приближается к
нулю и градиент почти не проходит — возникает «паралич». Слишком высокий
learning rate вызывает перескакивание минимума или колебания. Число и ширина
слоёв определяют ёмкость: слишком маленькая сеть недообучается, чрезмерная
может переобучиться. Поэтому сеть выбирают по test error, а не по train loss.
