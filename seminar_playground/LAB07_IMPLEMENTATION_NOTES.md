# Заметки реализации ЛР7

ЛР7 добавлена рядом с `training_engine.py`; код ЛР6 не переписан. `lab07_engine.py` поддерживает произвольные размеры, tanh, линейный выход для regression и устойчивый softmax + cross-entropy для classification, full-batch SGD/Adam, состояние Adam и Continue.

Нормализация, импутация и one-hot строятся только по Train. Временные окна создаются хронологически, а Control раскрывается отдельной кнопкой. Demo-наборы генерируются фиксированным seed и помечаются как demo. Вариантных файлов в текущем репозитории нет — см. `BLOCKED_BY_VARIANT_DATA.md`.

Orange интегрируется офлайн ZIP-пакетом. `.ows` намеренно не генерируются без установленного и проверенного Orange.
