# Памятка студента: ЛР7

1. Посмотрите первые строки, размеры, источник и подсказку типа задачи.
2. Сформулируйте гипотезу и явно выберите Features, Target и (для ряда) Time/Lag.
3. Обучайте сеть кнопкой Continue; графики строятся по текущей истории NumPy, а не заранее.
4. Сохраните минимум две архитектуры при одинаковом Train/Test и сравните параметры, Loss и GF/BF.
5. Только после выбора нажмите финальную оценку Control.
6. Скачайте ZIP для Orange и заметки Markdown.

Регрессия/прогноз: GF — объект с абсолютной ошибкой не выше указанного допуска. Классификация: GF — правильные классы, BF — ошибки. Демонстрационные наборы не являются данными индивидуального варианта.
