# Руководство преподавателя: ЛР7

## Маршрут на 90 минут

1. 0–17 мин: предложить определить тип задачи по таблице и графику.
2. 17–30 мин: подтвердить Features/Target/Time и обсудить разбиение Train/Test/Control.
3. 30–45 мин: обучить demo или вариантную MLP порциями, наблюдая реальные Loss и предметный график.
4. 45–60 мин: скачать пакет Orange и сравнить смысл метрик.
5. 60–85 мин: сохранить две архитектуры, выбрать по Test, затем открыть Control.
6. 85–90 мин: защита гипотезы «изменение → наблюдение → вывод».

## Ожидаемые эффекты

Малая сеть может недообучаться, большая — снизить Train Loss и ухудшить Test. Это интерпретация конкретного запуска, а не универсальный порог. Для временного ряда перемешивание запрещено; для классификации accuracy нужно сопоставлять с macro-F1 и confusion matrix.

Для демонстрации нестабильности увеличьте learning rate или init scale; для overfit увеличьте сеть и уменьшите Train. Control не используйте для выбора модели.
