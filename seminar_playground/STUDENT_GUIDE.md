# Памятка студента

## ЛР6

Откройте «ЛР6 · Как обучается сеть» и пройдите четыре модуля по порядку: один нейрон → градиентный спуск → живая MLP → «Почини нейросеть». В каждом модуле сначала сделайте наблюдение, затем ответьте на проверочный вопрос.

## ЛР7

Откройте «ЛР7 · Как выбрать модель» и пройдите пять этапов:

1. **Данные:** выберите учебный набор или загрузите Train/Test/Control, изучите строки и график.
2. **Постановка:** назначьте Features → Target; для ряда Time → Value → Lag.
3. **Обучение:** нажмите «Запустить обучение», затем «Продолжить +N эпох».
4. **Сравнение:** сохраните два эксперимента, выберите модель по Test и зафиксируйте её.
5. **Экспорт:** откройте Control один раз и скачайте ZIP для Orange.

Демонстрационные наборы не являются данными варианта. GF/BF для регрессии и прогноза используют явный абсолютный допуск; в классификации GF — правильные объекты, BF — ошибки.
